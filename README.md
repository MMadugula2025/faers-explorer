# FAERS Adverse Event Explorer

A dashboard for exploring FDA Adverse Event Reporting System (FAERS) data —
search a drug and see its reported adverse event trends and top reported
reactions, built from real, self-cleaned FDA data.

> **Note on the data:** FAERS is a voluntary, self-reported surveillance
> system. A drug and a reaction appearing together in reports does **not**
> mean the drug caused the reaction — this tool is for exploring reporting
> trends, not for assessing drug safety.

## Project structure

```
faers-explorer/
  app.py                  Streamlit dashboard (reads from faers_clean.db)
  clean_faers_simple.py   Cleans ONE quarter (DEMO, DRUG, REAC) — start here
  clean_faers.py          Cleans MULTIPLE quarters combined — use once comfortable
  requirements.txt        Python dependencies
  raw_data/                Downloaded FDA files go here (not tracked in git)
  faers_clean.db           Generated by the cleaning scripts (not tracked in git)
```

## 1. Download the raw data

FAERS Quarterly Data Files, published by the FDA:
**https://fis.fda.gov/extensions/FPD-QDE-FAERS/FPD-QDE-FAERS.html**

On that page:
1. Scroll to **"Quarterly Data Extract Files"**
2. Pick a quarter (start with just one, e.g. **2026 Q1**)
3. Click the **ASCII** download link (not XML/SGML)
4. Unzip it and place the extracted folder inside `raw_data/`, so you end up
   with a path like:
   ```
   raw_data/faers_ascii_2026q1/ASCII/DEMO26Q1.txt
   raw_data/faers_ascii_2026q1/ASCII/DRUG26Q1.txt
   raw_data/faers_ascii_2026q1/ASCII/REAC26Q1.txt
   ```

To add more quarters later, download additional quarters from the same page
and repeat.

## 2. Set up your environment

```
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 3. Clean the data

Start with the single-quarter script (update `QUARTER_CODE` inside it if
your quarter differs from `26Q1`):

```
python3 clean_faers_simple.py
```

This produces `faers_clean.db`, a local SQLite database with three cleaned,
joined tables: `demo`, `drug`, `reac`.

Once that works and you understand it, `clean_faers.py` handles multiple
quarters combined — edit the `QUARTERS` list inside it to match every
quarter you've downloaded.

## 4. Run the dashboard

```
streamlit run app.py
```

Opens at `http://localhost:8501`. Search a drug name (e.g. `ASPIRIN`,
`MOUNJARO`, `PREDNISONE`) to see total reports, a reports-by-year chart, and
top reported reactions.

## Known limitations / next steps

- **No causation.** See the note at the top — FAERS reports co-occurrence,
  not cause.
- **Reporting volume grows over time.** Raw yearly counts aren't adjusted
  for FAERS' overall growth in total reports. A stronger version would show
  each drug's share of total reports per year, not raw counts.
- **Drug name matching is approximate.** Cleaning currently strips
  dosage/units and punctuation, but doesn't merge brand ↔ generic names
  (e.g. "TYLENOL" vs "ACETAMINOPHEN" won't match) or split combination drugs
  cleanly. A mapping table (e.g. from RxNorm) would improve this.
- **Only a few quarters loaded so far.** Trend charts get meaningfully more
  useful as more quarters are added — see step 1 to add more.

## Data dictionary

Each FDA download includes `ASC_NTS.pdf` in the `ASCII/` folder — this
explains every column in every file. Worth a skim when you need to
understand a field that isn't obvious.
